# IXPingCommand

**Plugin para PocketMine-MP API 5 que permite a los jugadores ver su latencia en el servidor con el comando `/ping`.**

## Descripción

Este plugin agrega el comando `/ping` a tu servidor de Minecraft Pocket Edition (PocketMine-MP 5). Cuando un jugador ejecuta este comando, el plugin responde con su latencia (ping) en milisegundos.

## Características

- Comando `/ping`: Muestra el ping del jugador que ejecuta el comando.
- Fácil de usar y configurar.
- Compatible con PocketMine-MP 5.
- Sin dependencias adicionales.

## Instalación

1. Descarga el archivo `.zip` del plugin.
2. Colócalo en la carpeta `plugins` de tu servidor PocketMine-MP 5 y descomprimelo.
3. Reinicia tu servidor.
4. ¡Listo! Los jugadores ahora pueden usar el comando `/ping`.

## Comandos

- `/ping`: Muestra el ping del jugador que ejecuta el comando.
